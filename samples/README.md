# Sample exports

Generated by `bun scripts/generate-samples.ts` through the full export pipeline:
conversation brief → outline → per-section hybrid retrieval → grounded JSON →
validation → PDF/DOCX/PPTX renderers.

The chunks come from the seeded fixture library in `tests/documents/fixtures.ts`,
not the live database: this environment has no authenticated Supabase session.
The provenance path (chat history + chunks, no templates, no model memory) is the
production path; only the source library is substituted.

Files:

- `zurich-claims-proposal.pdf` — proposal mode, A4, contents page, sources.
- `zurich-claims-proposal.docx` — same model, Word styles, tables, TOC.
- `zurich-claims-pitch-deck.pptx` — pitch mode, takeaway slides with native
  tables, metric cards, per-slide source footnote and speaker notes.

Regenerate with `bun scripts/generate-samples.ts`.
